提供agnes-ai在线网页版（填入API就可以在线使用）

KEY 池与接口调度机制
- 接口轮流：默认开启「4 个接口地址轮流使用」，每次请求自动切换到下一个接口（apihub .cn → apihub .com → api .cn → api .com 循环），把压力分摊到 4 个端点；可在 KEY 池管理里关掉，固定用某一个地址。
- KEY 轮询：批量粘贴（换行 / 逗号 / 空格分隔），round-robin 轮询。
- 失败重试的 KEY 选择策略：首次生成用轮询取到的 KEY；一旦失败需要重新生成时，优先从"今天还没用过"的 KEY 里随机挑一个；今天全部用过则从剩余可用 KEY（排除本次已试过的）中随机挑。每个 KEY 面板里都有「今日已用 / 今日未用」标识。
- 失败自动换 KEY 重新生成：401/403 无效、400/402 余额不足、429 限流、5xx、网络失败均覆盖，状态栏实时显示切换过程。
- 单 KEY 连续失败 3 次冷却 5 分钟后自动归队。
- 视频任务「创建 + 轮询」固定在同一接口地址，不会跨端点查询任务。
重新生成（全模块覆盖）
- 每个生成模块在首次执行后都会出现「🔄 重新生成」按钮：提示词、设置、图片全部不变，无感重新提交一次；由于 KEY 池与接口轮询，重新生成会自动走下一个 KEY 和下一个接口，适合"换个运气/换条通道"打磨结果。
- 覆盖模块：AI 对话（撤回上一句回复重新回答）、短篇小说、提示词优化、快写提示词、反推提示词、去 AI 味、运营写文、文生图、封面生成器、图生图、文生视频、图生视频。
接口约定
全部走 Agnes APIHub OpenAI 兼容接口，四个地址可切换：
- https://apihub.agnes-ai.cn/v1（国内站）
- https://apihub.agnes-ai.com/v1（国际站）
- https://api.agnes-ai.cn/v1（国内直连，原在线版默认）
- https://api.agnes-ai.com/v1（国际直连）
路径：对话与视觉 /chat/completions、生图 /images/generations（图生图附带 image 字段）、视频 /video/generations 异步任务、模型清单 /models。
移动端优化
- 侧边栏改为抽屉式导航，汉堡按钮 + 遮罩关闭
- 触控目标 ≥ 42px，按钮全宽，表单纵向堆叠
- 统计卡 / 快捷入口 / 画廊自适应网格
- viewport-fit=cover 适配刘海屏
GitHub Pages 部署（3 步）
1. 新建公开仓库，上传本目录的 index.html（和本 README）。
2. 仓库 Settings → Pages → Source 选 main 分支根目录。
3. 约 1 分钟后访问 https://<用户名>.github.io/<仓库名>/。
